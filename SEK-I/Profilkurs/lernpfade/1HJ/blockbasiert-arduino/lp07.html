In Zweierteams baut ihr in drei Sitzungen einen Wächter: Ein echter Sensor misst, der Arduino vergleicht mit einem Schwellenwert, und zwei LEDs zeigen an: grün = alles in Ordnung, rot = jetzt handeln. Heute plant ihr, programmiert in Tinkercad, übersetzt die Blöcke in C++ und modelliert ein Gehäuse für den 3D-Drucker. Entscheidet euch für ein Projekt:

A · Gießwächter

Zimmerpflanze im Wohnzimmer

Die Pflanzen stehen in Übertöpfen mit Wasservorrat. Von außen sieht niemand, wie viel Wasser noch drin ist.

Sensor: Wasserstandssensor an A0, steht im Wasservorrat.

genug Wasser im Topf
Wasserstand unter dem Schwellenwert: gießen!

Tinkercad: Potentiometer an A0 als Ersatz für den Wasserstandssensor.

B · Filterwächter

Wasserfilter in der Küche

Der Tischwasserfilter holt gelöste Salze aus dem Leitungswasser. Ist die Kartusche verbraucht, schmeckt man es nicht sofort.

Sensor: TDS-Sensor an A1, misst gelöste Stoffe in ppm im gefilterten Wasser.

Filter arbeitet
TDS über dem Schwellenwert: Kartusche wechseln!

Tinkercad: Potentiometer an A1 als Ersatz für den TDS-Sensor.

C · Lüftungswächter

Heizkeller im Haus

Im Heizkeller ist es warm, oft trocknet dort Wäsche. Wird zu selten gelüftet, bildet sich Schimmel an den Wänden.

Sensor: DHT11 an Pin 2, misst Temperatur und Luftfeuchte.

Luft in Ordnung
Temperatur und Luftfeuchte zu hoch: lüften!

Tinkercad: TMP36 an A2 (Temperatur) und Potentiometer an A3 (Luftfeuchte), einen DHT11 gibt es dort nicht.

Für alle Projekte gleich: die Anzeige

LED grün an Pin 7, LED rot an Pin 8, jede über 220 Ω (rot-rot-braun) an GND. Es leuchtet immer genau eine LED. Den Schwellenwert wählt ihr heute vorläufig, in Sitzung 08 messt ihr ihn am echten Sensor nach.

Gehäuse aus dem 3D-Drucker: so geht's

  1. Tinkercad › 3D-Entwurf anlegen, Quader auf Außenmaß ziehen. Einen zweiten Quader im Innenmaß als Bohrung einsetzen, 2 mm über dem Boden: Wand und Boden bleiben 2 mm stark.
  2. Aussparungen als Bohrung: Zylinder Ø 5,2 mm für jede LED, Quader für USB-Buchse (12 × 11 mm) und Sensorkabel. Plant je Seite 0,5 mm Spiel ein.
  3. Deckel als flache Platte extra bauen, gern mit eingeprägtem Namen (Text als Bohrung, 1 mm tief).
  4. Alles markieren, gruppieren, Exportieren › .STL. Die Lehrkraft druckt die Gehäuse bis Sitzung 08. Je kleiner, desto schneller.

Aufgaben

  • Aufgabe 1 · Bauteile und Materialien: Tragt alle Bauteile ein, die ihr braucht, auch Kabel, Steckbrett und Gehäuse (Material / Typ / Wert, Anzahl, Anschluss am Arduino).
  • Aufgabe 2 · Struktogramm: Plant das Programm mit Anweisung, Verzweigung (wenn … dann … sonst) und Wiederholung (für immer), bevor ihr Blöcke setzt.
  • Aufgabe 3 · Gehäuse vermessen: Messt Arduino, Steckbrett und Sensor, rechnet Innen- und Außenmaß aus, plant die Öffnungen und baut das Gehäuse im Tinkercad-3D-Entwurf.
  • Aufgabe 4 · Vom Block zur C++-Zeile: Programmiert den Wächter in Tinkercad mit Blöcken, stellt auf „Blöcke + Text“ und tragt zu jedem Steuerelement Block und C++-Zeile ein.
  • Prüfen: Wählt unten euer Projekt und beantwortet zu jeder Aufgabe die Impulsfragen. Sind alle richtig, erscheint der Erwartungshorizont mit Bauplan: Vergleicht und verbessert euer Blatt.

    digitalWrite(8, LOW);
  }

}

Projekt C · C++ · tinkercad-projekt-c.ino
// Projekt C · Lüftungswächter, Tinkercad-Fassung (Sitzung 07)
// TMP36 an A2 (Temperatur), Potentiometer an A3 (ersetzt die Luftfeuchte)
// LED grün an Pin 7, LED rot an Pin 8 (je mit 220 Ohm an GND)
int t = 0;
int h = 0;
int maxT = 25;
int maxH = 60;

void setup()
{
  pinMode(A2, INPUT);
  pinMode(A3, INPUT);
  pinMode(7, OUTPUT);
  pinMode(8, OUTPUT);
  Serial.begin(9600);
}

void loop()
{
  t = -40 + 0.488155 * (analogRead(A2) - 20);
  h = map(analogRead(A3), 0, 1023, 0, 100);
  Serial.print("Temperatur: ");
  Serial.print(t);
  Serial.print(" C, Luftfeuchte: ");
  Serial.print(h);
  Serial.println(" %");
  if (t > maxT && h > maxH) {
    // warm und feucht: lüften, rot
    digitalWrite(7, LOW);
    digitalWrite(8, HIGH);
  } else {
    // Luft in Ordnung: grün
    digitalWrite(7, HIGH);
    digitalWrite(8, LOW);
  }
  delay(2000); // 2 Sekunden warten
}
