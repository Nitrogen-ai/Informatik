Mein Arduino-Projekt: Tinkercad trifft echte Hardware

07

Das lernst du

Du wählst ein Arduino-Projekt (einfach, mittel oder knifflig), planst es nach dem EVA-Prinzip, baust und programmierst es in Tinkercad und lädst den C++-Code auf einen echten Arduino.

Material · Informationstext

Vom Tinkercad zum echten Arduino. Tinkercad simuliert nur. Damit dein Projekt wirklich leuchtet, misst oder piept, lädst du den C++-Code auf einen echten Arduino Uno. Das geht im Browser mit dem Arduino Cloud Editor (Chrome oder Edge, kostenloses Arduino-Konto):

  1. In Tinkercad: Code › Ansicht „Text“ › gesamten Code markieren (Strg+A) und kopieren (Strg+C). Alternativ lädt der Pfeil ⬇ eine .ino-Datei herunter.
  2. app.arduino.cc öffnen › Sketches › „+ Sketch“, Beispielcode löschen, eigenen Code einfügen. Bei M3 und K3 nimmst du die Echt-Version von der Karte (DHT22 statt TMP36).
  3. Schaltung auf dem Steckbrett nachbauen, ohne dass der Arduino am USB-Kabel hängt. Pins 0 und 1 bleiben frei.
  4. Arduino per USB anstecken, oben „Arduino Uno“ und den Anschluss (Port) wählen. Beim ersten Mal fragt der Editor nach dem Arduino Cloud Agent, ein kleines Hilfsprogramm, das die Schule einmalig installiert.
  5. ✓ Überprüfen, dann → Hochladen. Messwerte zeigt der Serial Monitor (9600 Baud).

Bibliotheken wie Adafruit_NeoPixel (LED-Ring) und DHT (DHT22) sind im Cloud Editor schon vorhanden, du musst nichts installieren. Sicherheit: nur ohne Strom umstecken, jede LED mit Vorwiderstand, den LED-Ring mit ring.setBrightness(40) dimmen (USB liefert nur etwa 500 mA).

Tinkercad und Kurskiste unterscheiden sich manchmal: Für den Wasserstandssensor nimmst du in Tinkercad den Bodenfeuchtigkeitssensor, für den DHT22 den Temperatursensor TMP36, für den TDS-Sensor ein Potentiometer. Den LED-Ring WS2812 gibt es in Tinkercad als NeoPixel-Ring 12.

Aufgaben

  • Wähle eine der neun Projektkarten unten (Aufgabe 1).
  • Plane dein Projekt nach dem EVA-Prinzip: Was liest es ein, was entscheidet das Programm, was gibt es aus? Lege für jedes Bauteil den Pin fest. Pins 0 und 1 bleiben frei (Aufgabe 2).
  • Baue und programmiere das Projekt in Tinkercad, lass Messwerte im Seriellen Monitor anzeigen und ergänze mindestens drei Kommentare (Aufgabe 3).
  • Übertrage den Code mit dem Arduino Cloud Editor auf den echten Arduino (Anleitung oben, Aufgabe 4).
  • Sichere Code und Foto/Video im Classroom (Leistungsnachweis unten) und beschreibe, was in Tinkercad anders war als am echten Arduino.

E1 Lauflicht ★ einfach💡 Licht & Deko

Vier farbige LEDs leuchten nacheinander auf und laufen wie eine Lichterkette hin und her.

Tinkercad
  • 4 LEDs (blau, gelb, weiß, grün)
  • 4 Widerstände 220 Ω
Echter Arduino (Kurskiste)
  • 4 LEDs (blau, gelb, weiß, grün)
  • 4 Widerstände 220 Ω
  • Jumperkabel
Schaltung
  • LEDs über je 220 Ω an Pin 2, 3, 4, 5
  • alle Kathoden (kurzes Bein) an GND
Neu für dich
  • digitalWrite(pin, HIGH/LOW)
  • delay(ms)
So gehst du vor
  1. Baue die vier LEDs nebeneinander auf die Steckplatine.
  2. Programmiere mit Blöcken: LED an, kurz warten, LED aus, nächste LED.
  3. Ergänze den Rückweg, sodass das Licht hin- und herläuft.
Code-Baustein
digitalWrite(2, HIGH); delay(150); digitalWrite(2, LOW);
digitalWrite(3, HIGH); delay(150); digitalWrite(3, LOW);
// ... Pin 4 und 5, dann zurück

Erweiterung: Schreibe den Hinweg mit einer for-Schleife (for (int pin = 2; pin <= 5; pin++)) und baue ein zweites Muster ein, z. B. alle blinken gleichzeitig.

E2 SOS-Leuchtfeuer ★ einfach🆘 Kommunikation & Seenot

Eine LED und ein Summer senden zusammen das Notsignal SOS im Morsecode: drei kurz, drei lang, drei kurz.

Tinkercad
  • 1 LED (weiß)
  • 1 Widerstand 220 Ω
  • Piezo
Echter Arduino (Kurskiste)
  • 1 LED (weiß)
  • 1 Widerstand 220 Ω
  • Buzzer
  • Jumperkabel
Schaltung
  • LED über 220 Ω an Pin 8
  • Piezo/Buzzer: + an Pin 9, − an GND
Neu für dich
  • tone(pin, frequenz) / noTone(pin)
  • eigene Funktion: void zeichen(int dauer)
So gehst du vor
  1. Plane die Zeiten: kurz = 200 ms, lang = 600 ms, Pause = 200 ms.
  2. Programmiere ein kurzes Zeichen: LED an, Ton an, warten, beides aus, Pause.
  3. Setze S, O, S zusammen und teste, ob man das Signal erkennt.
Code-Baustein
void zeichen(int dauer) {
  digitalWrite(8, HIGH); tone(9, 880);
  delay(dauer);
  digitalWrite(8, LOW); noTone(9);
  delay(200);
}

Erweiterung: Morse deinen Vornamen. Eine Morsetabelle findest du unter „Morsecode“ in jedem Lexikon.

E3 Ampel mit Fußgängerampel ★ einfach🚦 Verkehr

Deine Ampel aus LP06 bekommt eine Fußgängerampel, die nur Grün zeigt, solange die Autos Rot haben.

Tinkercad
  • 5 LEDs (2 × rot, gelb, 2 × grün)
  • 5 Widerstände 220 Ω
Echter Arduino (Kurskiste)
  • 5 LEDs
  • 5 Widerstände 220 Ω
  • Jumperkabel
Schaltung
  • Autos: rot 13, gelb 12, grün 11
  • Fußgänger: rot 10, grün 9
  • alle Kathoden an GND
Neu für dich
  • mehrere digitalWrite je Phase
  • eigene Funktion setze(…) (Erweiterung)
So gehst du vor
  1. Erweitere deine Planungstabelle aus LP06 um zwei Spalten (Fußgänger rot/grün).
  2. Plane eine Räumzeit: Alle haben kurz Rot, bevor jemand Grün bekommt.
  3. Programmiere die Phasen in „für immer“ und prüfe, dass nie beide Grün haben.
Code-Baustein
// Phase: Fußgänger gehen
digitalWrite(13, HIGH); digitalWrite(12, LOW); digitalWrite(11, LOW);
digitalWrite(10, LOW);  digitalWrite(9, HIGH);
delay(4000);

Erweiterung: Lass das Fußgänger-Grün vor dem Umschalten dreimal blinken.

M1 Bedarfsampel mit Taster ★★ mittel🚦 Verkehr

Die Autos haben Dauergrün. Erst wenn jemand den Taster drückt, schaltet die Ampel für Fußgänger:innen um.

Tinkercad

Echter Arduino (Kurskiste)

M2 Füllstandswarner ★★ mittel🌊 Umwelt & Hochwasser

Ein Sensor misst, wie hoch Wasser steht. Grün heißt trocken, Gelb heißt „steigt“, Blau und ein Ton heißen Alarm.

Tinkercad
  • Bodenfeuchtigkeitssensor (statt Wasserstandssensor)
  • 3 LEDs (grün, gelb, blau)
  • 3 Widerstände 220 Ω
  • Piezo
Echter Arduino (Kurskiste)
  • Wasserstandssensor (6 im Kurs)
  • 3 LEDs
  • 3 Widerstände 220 Ω
  • Buzzer
  • Becher mit Wasser
Schaltung
  • Sensor: S an A0, + an 5V, − an GND
  • LEDs: grün 11, gelb 12, blau 13
  • Buzzer an Pin 9
Neu für dich
  • analogRead(A0): Wert von 0 bis 1023
  • Serial.begin(9600) / Serial.println(wert)
  • if … else if … else
So gehst du vor
  1. Lies den Sensor mit analogRead(A0) und gib den Wert im Seriellen Monitor aus.
  2. Miss die Werte für trocken, halb und voll und lege zwei Grenzwerte fest.
  3. Programmiere mit falls … sonst falls … sonst die passende LED.
Code-Baustein
int wert = analogRead(A0);
Serial.println(wert);
if (wert < 100) { /* grün */ }
else if (wert < 350) { /* gelb */ }
else { /* blau + Ton */ }

Erweiterung: Am echten Sensor nur den unteren Teil mit den Streifen eintauchen. Profi: den Sensor über einen Digitalpin nur beim Messen mit Strom versorgen, dann rostet er langsamer.

M3 Klimawächter fürs Klassenzimmer ★★ mittel🌡️ Gesundheit & Klima

Die Station misst die Raumtemperatur und zeigt mit LEDs: zu kalt (blau), angenehm (grün), zu warm (gelb).

Tinkercad
  • Temperatursensor TMP36
  • 3 LEDs (blau, grün, gelb)
  • 3 Widerstände 220 Ω
Echter Arduino (Kurskiste)
  • DHT22 Temperatur- und Feuchtesensor (11 im Kurs)
  • 4 LEDs (blau, grün, gelb, weiß)
  • 4 Widerstände 220 Ω
Schaltung
  • Tinkercad: TMP36 Mitte an A0, links 5V, rechts GND
  • echt: DHT22 + an 5V, out an Pin 2, − an GND
  • LEDs: gelb 10, grün 11, blau 12 (weiß 9: lüften)
Neu für dich
  • float (Kommazahlen)
  • Umrechnung Spannung → °C
  • Bibliothek einbinden: #include <DHT.h>
So gehst du vor
  1. Baue die Tinkercad-Version mit TMP36 und lass die Temperatur im Seriellen Monitor anzeigen.
  2. Programmiere die drei Bereiche unter 20 °C, 20 bis 24 °C, über 24 °C.
  3. Übertrage es auf den DHT22 (andere Code-Version, Bibliothek „DHT sensor library“).
Code-Baustein
// Tinkercad (TMP36)
float spannung = analogRead(A0) * 5.0 / 1024.0;
float temperatur = (spannung - 0.5) * 100.0;

// echt (DHT22)
float temperatur = dht.readTemperature();

Erweiterung: Echte Version: Die weiße LED leuchtet, wenn die Luftfeuchte über 60 % liegt (Zeit zum Lüften).

K1 Lichtring mit Drehregler ★★★ knifflig🌈 Licht & Design

Ein Ring aus 12 Farb-LEDs zeigt einen Regenbogen-Schweif, der im Kreis läuft. Ein Drehregler bestimmt das Tempo.

Tinkercad
  • NeoPixel-Ring 12
  • Potentiometer
Echter Arduino (Kurskiste)
  • LED-Ring WS2812 mit 12 LEDs (3 im Kurs)
  • Widerstand 330 Ω (Datenleitung)
  • Potentiometer
  • Jumperkabel
Schaltung
  • Ring: IN/DI an Pin 6 (echt über 330 Ω), 5V an 5V, GND an GND
  • Potentiometer: Mitte an A0, außen 5V und GND
Neu für dich
  • #include <Adafruit_NeoPixel.h>
  • ring.setPixelColor(nr, ring.Color(r, g, b)); ring.show();
  • map(wert, 0, 1023, 30, 300)
  • Modulo %
So gehst du vor
  1. Wechsle in Tinkercad auf die Ansicht „Text“ und binde die Bibliothek Adafruit_NeoPixel ein.
  2. Färbe zuerst eine einzelne LED, dann alle zwölf nacheinander (for-Schleife).

#include <Adafruit_NeoPixel.h>
Adafruit_NeoPixel ring(12, 6, NEO_GRB + NEO_KHZ800);

}

Erweiterung: Baue einen zweiten Modus (z. B. alle LEDs pulsieren), den ein Taster umschaltet.

K2 Reaktionsspiel ★★★ knifflig🎮 Spiel & Sport

Nach einer zufälligen Wartezeit geht die LED an. Wer schnell drückt, sieht seine Reaktionszeit in Millisekunden. Wer zu früh drückt, fliegt raus.

Tinkercad
  • 1 LED (grün)
  • 1 Widerstand 220 Ω
  • Drucktaster
  • Piezo
Echter Arduino (Kurskiste)
  • 1 LED
  • 1 Widerstand 220 Ω
  • Taster
  • Buzzer
  • Jumperkabel
Schaltung
  • LED über 220 Ω an Pin 8
  • Taster zwischen Pin 2 und GND
  • Piezo/Buzzer an Pin 9
Neu für dich
  • random(min, max)
  • millis(): Millisekunden seit dem Start
  • while-Schleife
  • Variable für den Rekord
So gehst du vor
  1. Programmiere eine Zufallswartezeit mit random(2000, 5000).
  2. Miss die Zeit mit millis() vom Aufleuchten bis zum Tastendruck.
  3. Ergänze den Mogelschutz und einen Rekord, der sich die beste Zeit merkt.
Code-Baustein
digitalWrite(8, HIGH);
unsigned long start = millis();
while (digitalRead(2) == HIGH) { }   // warten auf Druck
unsigned long zeit = millis() - start;
Serial.println(zeit);

Erweiterung: Zwei Spieler:innen mit zwei Tastern: Wer zuerst drückt, gewinnt die Runde.

K3 Umweltstation mit Lichtring ★★★ knifflig🔬 Umwelt & Chemie

Der Lichtring wird zum Thermometer: Je wärmer, desto mehr LEDs leuchten, die Farbe zeigt kalt, angenehm oder warm. Bonus: ein TDS-Sensor misst gelöste Stoffe im Wasser.

Tinkercad
  • Temperatursensor TMP36
  • NeoPixel-Ring 12
  • Potentiometer (Platzhalter für den TDS-Sensor)
Echter Arduino (Kurskiste)
  • DHT22
  • LED-Ring WS2812 (12 LEDs)
  • Widerstand 330 Ω
  • Bonus: TDS-Sensor CQRobot (4 im Kurs)
  • Wasserproben
Schaltung
  • Tinkercad: TMP36 an A0, Ring an Pin 6, Potentiometer an A1
  • echt: DHT22 out an Pin 2, Ring DI über 330 Ω an Pin 6
  • TDS-Platine: A an A1, + an 5V, − an GND
Neu für dich
  • map() und constrain()
  • eigene Funktion zeigeTemperatur(float t)
  • zwei Bibliotheken gleichzeitig
So gehst du vor
  1. Baue M3 (Temperatur messen) und K1 (Ring ansteuern) zusammen.
  2. Rechne die Temperatur 15 bis 30 °C mit map() in 1 bis 12 LEDs um.
  3. Wähle die Farbe mit falls … sonst und teste am echten Arduino mit dem DHT22.
  4. Bonus: Vergleiche Leitungswasser, Mineralwasser und destilliertes Wasser mit dem TDS-Sensor.
Code-Baustein
int an = map((int)(t * 10), 150, 300, 1, 12);
an = constrain(an, 1, 12);
for (int i = 0; i < 12; i++) {
  ring.setPixelColor(i, i < an ? farbe : 0);
}
ring.show();

Erweiterung: Zeige abwechselnd Temperatur und Luftfeuchte auf dem Ring (z. B. Feuchte in Weiß).

  • E2 SOS-Leuchtfeuer · E2-sos-leuchtfeuer.ino
    // E2 SOS-Leuchtfeuer · Tinkercad und echter Arduino
// LED (weiß) mit 220 Ω an Pin 8, Piezo/Buzzer an Pin 9 und GND.
// Morse: kurz = 1 Einheit, lang = 3 Einheiten, Pause zwischen Buchstaben = 3 Einheiten.

const int LED = 8;
const int TON = 9;
const int EINHEIT = 200;   // Millisekunden

void zeichen(int dauer) {
  digitalWrite(LED, HIGH);
  tone(TON, 880);          // Ton mit 880 Hz
  delay(dauer);
  digitalWrite(LED, LOW);
  noTone(TON);
  delay(EINHEIT);          // kurze Pause nach jedem Zeichen
}

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  zeichen(EINHEIT); zeichen(EINHEIT); zeichen(EINHEIT);              // S  · · ·
  delay(2 * EINHEIT);
  zeichen(3 * EINHEIT); zeichen(3 * EINHEIT); zeichen(3 * EINHEIT);  // O  − − −
  delay(2 * EINHEIT);
  zeichen(EINHEIT); zeichen(EINHEIT); zeichen(EINHEIT);              // S  · · ·
  delay(7 * EINHEIT);      // Pause vor der Wiederholung
}

    // M1 Bedarfsampel mit Taster · Tinkercad und echter Arduino
// Autoampel rot 13, gelb 12, grün 11 · Fußgänger rot 10, grün 9 (je 220 Ω)
// Taster: ein Bein an Pin 2, das gegenüberliegende an GND (INPUT_PULLUP: gedrückt = LOW).

const int TASTER = 2;

void setze(int rot, int gelb, int gruen, int fRot, int fGruen, int ms) {
  digitalWrite(13, rot); digitalWrite(12, gelb); digitalWrite(11, gruen);
  digitalWrite(10, fRot); digitalWrite(9, fGruen);
  delay(ms);
}

void setup() {
  for (int pin = 9; pin <= 13; pin++) pinMode(pin, OUTPUT);
  pinMode(TASTER, INPUT_PULLUP);
}

void loop() {
  setze(LOW, LOW, HIGH, HIGH, LOW, 0);       // Grundzustand: Autos grün, Fußgänger rot
  if (digitalRead(TASTER) == LOW) {          // jemand drückt
    delay(2000);                             // kurze Wartezeit wie an einer echten Ampel
    setze(LOW,  HIGH, LOW, HIGH, LOW,  1000); // Gelb
    setze(HIGH, LOW,  LOW, HIGH, LOW,  1000); // alle Rot
    setze(HIGH, LOW,  LOW, LOW,  HIGH, 5000); // Fußgänger grün
    setze(HIGH, LOW,  LOW, HIGH, LOW,  1000); // Räumzeit
    setze(HIGH, HIGH, LOW, HIGH, LOW,  1000); // Rot-Gelb
  }
}
  • M2 Füllstandswarner · M2-fuellstandswarner.ino
    // M2 Füllstandswarner (Hochwasser-Alarm) · Tinkercad und echter Arduino
// Tinkercad: Bodenfeuchtigkeitssensor · echt: Wasserstandssensor (S an A0, + an 5V, − an GND)
// LEDs mit 220 Ω: grün 11, gelb 12, blau 13 (Alarm); Buzzer/Piezo an Pin 9.
// Die Grenzwerte 100 und 350 sind Startwerte: im Seriellen Monitor messen und anpassen!

const int SENSOR = A0;

void setup() {
  pinMode(11, OUTPUT);
  pinMode(12, OUTPUT);
  pinMode(13, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int wert = analogRead(SENSOR);     // 0 (trocken) bis 1023
  Serial.print("Wasserstand: ");
  Serial.println(wert);

  digitalWrite(11, LOW); digitalWrite(12, LOW); digitalWrite(13, LOW);
  noTone(9);
  if (wert < 100) {
    digitalWrite(11, HIGH);          // trocken bis niedrig
  } else if (wert < 350) {
    digitalWrite(12, HIGH);          // Wasser steigt
  } else {
    digitalWrite(13, HIGH);          // Alarm
    tone(9, 1000);
  }
  delay(500);

Adafruit_NeoPixel ring(ANZAHL, 6, NEO_GRB + NEO_KHZ800);

// Farbrad: 0..255 → Regenbogenfarbe (aus dem Adafruit-Beispiel „strandtest“)
uint32_t farbrad(byte pos) {
  pos = 255 - pos;
  if (pos < 85) return ring.Color(255 - pos * 3, 0, pos * 3);
  if (pos < 170) { pos -= 85; return ring.Color(0, pos * 3, 255 - pos * 3); }
  pos -= 170;
  return ring.Color(pos * 3, 255 - pos * 3, 0);
}

int start = 0;

void setup() {
  ring.begin();
  ring.setBrightness(40);   // WICHTIG am echten Ring: USB liefert nur ca. 500 mA
}

void loop() {
  int poti = analogRead(A0);                 // 0..1023
  int tempo = map(poti, 0, 1023, 30, 300);   // Wartezeit in ms
  for (int i = 0; i < ANZAHL; i++) {
    ring.setPixelColor(i, 0);                // alle aus
  }
  for (int k = 0; k < 4; k++) {              // Schweif aus 4 LEDs mit Regenbogenfarben
    int pos = (start + k) % ANZAHL;
    ring.setPixelColor(pos, farbrad((pos * 256 / ANZAHL) & 255));
  }
  ring.show();
  start = (start + 1) % ANZAHL;
  delay(tempo);
}

// LED (grün) mit 220 Ω an Pin 8, Taster zwischen Pin 2 und GND, Piezo/Buzzer an Pin 9.
// Ergebnisse im Seriellen Monitor (9600 Baud).

const int LED = 8, TASTER = 2, TON = 9;
unsigned long rekord = 0;    // 0 = noch kein Rekord

void setup() {
  pinMode(LED, OUTPUT);
  pinMode(TASTER, INPUT_PULLUP);
  Serial.begin(9600);
  randomSeed(analogRead(A5)); // offener Pin liefert Zufallsrauschen
}

void loop() {
  Serial.println("Mach dich bereit ...");
  while (digitalRead(TASTER) == LOW) {}      // warten, bis der Taster losgelassen ist
  unsigned long ziel = millis() + random(2000, 5000);
  while (millis() < ziel) {
    if (digitalRead(TASTER) == LOW) {        // Mogelschutz
      Serial.println("Zu früh gedrückt!");
      tone(TON, 200, 400);
      delay(1500);
      return;                                // neue Runde
    }
  }
  digitalWrite(LED, HIGH);
  tone(TON, 1000, 100);
  unsigned long start = millis();
  while (digitalRead(TASTER) == HIGH) {}     // warten auf den Druck
  unsigned long zeit = millis() - start;
  digitalWrite(LED, LOW);

  Serial.print("Reaktionszeit: ");
  Serial.print(zeit);
  Serial.println(" ms");
  if (rekord == 0 || zeit < rekord) {
    rekord = zeit;
    Serial.println("Neuer Rekord!");
    tone(TON, 1500, 300);
  }
  delay(2000);
}

  • K3 Umweltstation mit Lichtring · K3-umweltstation-echt.ino
    // K3 Umweltstation: Temperatur auf dem Lichtring · Version für den ECHTEN Arduino
// DHT22 an Pin 2 (wie M3), WS2812-Ring (12 LEDs) DI über 330 Ω an Pin 6, 5V, GND.
// Bonus: TDS-Sensor (CQRobot) A an A1, + an 5V, − an GND: misst gelöste Stoffe im Wasser in ppm.
// Bibliotheken: „Adafruit NeoPixel“, „DHT sensor library“.
#include <Adafruit_NeoPixel.h>
#include <DHT.h>

Adafruit_NeoPixel ring(12, 6, NEO_GRB + NEO_KHZ800);
DHT dht(2, DHT22);

void zeigeTemperatur(float t) {
  int an = map((int)(t * 10), 150, 300, 1, 12);
  an = constrain(an, 1, 12);
  uint32_t farbe;
  if (t < 20)       farbe = ring.Color(0, 0, 255);
  else if (t <= 24) farbe = ring.Color(0, 255, 0);
  else              farbe = ring.Color(255, 0, 0);
  for (int i = 0; i < 12; i++) {
    ring.setPixelColor(i, i < an ? farbe : 0);
  }
  ring.show();
}

float tdsMessen(float temperatur) {
  float u = analogRead(A1) * 5.0 / 1024.0;                // Spannung in V
  float u25 = u / (1.0 + 0.02 * (temperatur - 25.0));     // auf 25 °C umrechnen
  return (133.42 * u25 * u25 * u25 - 255.86 * u25 * u25 + 857.39 * u25) * 0.5;  // Formel des Herstellers
}

void setup() {
  ring.begin();
  ring.setBrightness(40);   // USB liefert nur ca. 500 mA
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  delay(2000);
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t)) {
    Serial.println("Sensorfehler: DHT22-Kabel prüfen");
    return;
  }
  Serial.print("Temperatur: "); Serial.print(t); Serial.print(" °C   Luftfeuchte: "); Serial.print(h);
  Serial.print(" %   TDS: "); Serial.print(tdsMessen(t)); Serial.println(" ppm");
  zeigeTemperatur(t);
}
