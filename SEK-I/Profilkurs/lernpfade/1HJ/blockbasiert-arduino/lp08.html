Heute zieht euer Wächter vom Bildschirm ins echte Leben: Ihr baut ihn ins gedruckte Gehäuse, ersetzt im Code das Ersatzbauteil durch den echten Sensor, testet ihn live und legt den Schwellenwert fest.

Vom Ersatzbauteil zum echten Sensor

Ersetzt im C++-Code nur die Zeilen, die den Sensor lesen, durch die Zeilen aus der Anschlusskarte. Vergleich und LEDs bleiben.

Projektin Tinkercadam echten Arduino
A GießwächterPotentiometer an A0analogRead(A0) bleibt. Neu ist der Wertebereich: trocken etwa 0, tief im Wasser bis etwa 650.
B FilterwächterPotentiometer an A1Die 30 Messungen und die TDS-Formel aus der Anschlusskarte einfügen, dann tds mit dem Schwellenwert vergleichen.
C LüftungswächterTMP36 an A2, Potentiometer an A3#include <DHT.h> und DHT dht(2, DHT11); oben, dht.begin(); im Setup, dann dht.readTemperature() und dht.readHumidity().

So ladet ihr den Code hoch

  1. USB-Kabel ab, dann die Kabel nach der Anschlusskarte stecken. Die Farbe im Bild zeigt den Pin, das farbige Schild am Arduino den Namen.
  2. Arduino anstecken und Arduino hochladen öffnen (Chrome oder Edge, ohne Konto).
  3. Code einfügen oder mit „Datei öffnen“ laden, dann „⬆ Auf Arduino laden“ klicken und den Arduino auswählen.
  4. Im Monitor unten auf der Seite erscheinen die Messwerte.

Sensor 1 · DHT11: Temperatur und Luftfeuchte

Anschlusskarte Sensor 1 · DHT11: Temperatur und Luftfeuchte
KabelSensorArduino
rotBein 15V
blauBein 2Pin 2
–Bein 3frei
schwarzBein 4GND
10 kΩWiderstandzwischen Bein 1 und Bein 2

Haltet den Sensor mit dem Gitter zu euch: Die Beinchen zählen von links 1, 2, 3, 4.

Im Monitor: Temperatur: 22.00 C, Luftfeuchte: 45.00 %. Haucht den Sensor an: Die Luftfeuchte steigt.

⚠ Achtung: Ohne den 10-kΩ-Widerstand (braun-schwarz-orange) kommt meist „Sensorfehler“. Bein 3 bleibt frei. Der DHT11 misst nur ganze Zahlen und ist auf etwa ±2 °C genau.
Testprogramm Sensor 1 · sensor-1-dht11.ino
// Sensor 1 · DHT11 (Temperatur und Luftfeuchte)
// Bein 1 an 5V, Bein 2 an Pin 2, Bein 3 frei, Bein 4 an GND
// 10 kΩ (braun-schwarz-orange) zwischen Bein 1 und Bein 2
#include <DHT.h>

DHT dht(2, DHT11);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  // nur alle 2 s messen
  delay(2000);
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t) || isnan(h)) {
    Serial.println("Sensorfehler: Kabel pruefen");
    return;
  }
  Serial.print("Temperatur: ");
  Serial.print(t);
  Serial.print(" C, Luftfeuchte: ");
  Serial.print(h);
  Serial.println(" %");
}

Sensor 2 · Wasserstandssensor

Anschlusskarte Sensor 2 · Wasserstandssensor
KabelSensorArduino

Die Beschriftung S + − steht auf der roten Platine unter den Pins. Die Kabelfarben dürft ihr frei wählen, wichtig ist, wo sie stecken.

Im Monitor: Wasserstand: 412. Trocken steht dort etwa 0, je tiefer der Sensor im Wasser steckt, desto größer die Zahl (bis etwa 600–700).

⚠ Achtung: Nur die Fläche mit den Streifen ins Wasser tauchen, Pins und Bauteile oben bleiben trocken. Den Sensor danach abtrocknen.
Testprogramm Sensor 2 · sensor-2-wasserstand.ino
// Sensor 2 · Wasserstandssensor
// Kabel: S an A0 (gelb), + an 5V (rot), - an GND (schwarz)

void setup() {
  Serial.begin(9600);
}

void loop() {
  // 0 = trocken ... ca. 600-700 = tief im Wasser
  int wert = analogRead(A0);
  Serial.print("Wasserstand: ");
  Serial.println(wert);
  delay(1000);
}

Sensor 3 · CQRobot TDS: Leitfähigkeit von Wasser

Anschlusskarte Sensor 3 · CQRobot TDS: Leitfähigkeit von Wasser
KabelSensorArduino
grünSignalA1
rot+5V
schwarz−GND

Das Kabel aus der Packung steckt im dreipoligen Stecker der schwarzen Platine (− + A), die Sonde im zweipoligen. Die ersten Werte nach dem Start sind zu hoch, nach etwa 10 s ist die Messung ruhig.

Im Monitor: Spannung: 1.47 V, TDS: 565 ppm (Leitungswasser). Eine Prise Salz lässt den Wert steigen. Über etwa 1000 ppm misst der Sensor ungenau.

⚠ Achtung: Nur die Sonde ins Wasser, die Platine bleibt trocken. Sonde danach mit destilliertem Wasser abspülen. Nicht zusammen mit dem Wasserstandssensor im selben Gefäß messen.
Testprogramm Sensor 3 · sensor-3-tds.ino
// Sensor 3 · CQRobot Ocean TDS (Leitfähigkeit)
// Kabel: grün (Signal) an A1, rot (+) an 5V, schwarz (-) an GND
// Formel aus dem CQRobot-Wiki, Wassertemperatur fest 25 °C
float wassertemperatur = 25.0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  // 30 Messungen mitteln
  long summe = 0;
  for (int i = 0; i < 30; i++) {
    summe += analogRead(A1);
    delay(20);
  }
  float spannung = summe / 30.0 * 5.0 / 1024.0;
  float faktor = 1.0 + 0.02 * (wassertemperatur - 25.0);
  float v = spannung / faktor;
  float tds = (133.42 * v * v * v - 255.86 * v * v + 857.39 * v) * 0.5;
  Serial.print("Spannung: ");
  Serial.print(spannung, 2);
  Serial.print(" V, TDS: ");
  Serial.print(tds, 0);
  Serial.println(" ppm");
  delay(1000);
}

Wenn es nicht klappt

  • Keine LED leuchtet: Das lange Bein der LED zeigt zum Pin, das kurze über den Widerstand zu GND.
  • Monitor bleibt leer: Serial.begin(9600); im Setup? Richtigen Anschluss gewählt?
  • DHT11 meldet „Sensorfehler“: 10-kΩ-Widerstand zwischen Bein 1 und Bein 2 prüfen.
  • TDS-Werte springen: Die ersten 10 s nach dem Start sind zu hoch, dann ist der Wert ruhig.
  • Gehäuse noch nicht fertig: Erst auf dem Steckbrett testen, dann einbauen.

  • Musterlösung A · Gießwächter (echter Sensor) · projekt-a-pflanze.ino
    // Projekt A · Gießwächter für Zimmerpflanzen (Musterlösung)
// Wasserstandssensor: S an A0, + an 5V, - an GND
// LED grün an Pin 7, LED rot an Pin 8 (je mit 220 Ohm an GND)
// Schwellenwert selbst messen: Sensor fast trocken = nachgießen
int schwelle = 200;

void setup() {
  pinMode(7, OUTPUT);
  pinMode(8, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int wert = analogRead(A0);
  Serial.print("Wasserstand: ");
  Serial.println(wert);
  if (wert < schwelle) {
    // zu wenig Wasser: rot
    digitalWrite(7, LOW);
    digitalWrite(8, HIGH);
  } else {
    // genug Wasser: grün
    digitalWrite(7, HIGH);
    digitalWrite(8, LOW);
  }
  delay(1000);
}

    // Projekt B · Filterwächter für den Wasserfilter (Musterlösung)
// CQRobot TDS: grün (Signal) an A1, rot (+) an 5V, schwarz (-) an GND
// LED grün an Pin 7, LED rot an Pin 8 (je mit 220 Ohm an GND)
// Schwellenwert selbst messen: Leitungswasser und frisch gefiltertes Wasser vergleichen
float schwelle = 400.0;
float wassertemperatur = 25.0;

void setup() {
  pinMode(7, OUTPUT);
  pinMode(8, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  // 30 Messungen mitteln
  long summe = 0;
  for (int i = 0; i < 30; i++) {
    summe += analogRead(A1);
    delay(20);
  }
  float spannung = summe / 30.0 * 5.0 / 1024.0;
  float faktor = 1.0 + 0.02 * (wassertemperatur - 25.0);
  float v = spannung / faktor;
  float tds = (133.42 * v * v * v - 255.86 * v * v + 857.39 * v) * 0.5;
  Serial.print("TDS: ");
  Serial.print(tds, 0);
  Serial.println(" ppm");
  if (tds > schwelle) {
    // Filter filtert kaum noch: rot
    digitalWrite(7, LOW);
    digitalWrite(8, HIGH);
  } else {
    // Filter arbeitet: grün
    digitalWrite(7, HIGH);
    digitalWrite(8, LOW);
  }
  delay(1000);
}
  • Musterlösung C · Lüftungswächter (echter Sensor) · projekt-c-heizkeller.ino
    // Projekt C · Lüftungswächter für den Heizkeller (Musterlösung)
// DHT11: Bein 1 an 5V, Bein 2 an Pin 2, Bein 3 frei, Bein 4 an GND, 10 kOhm zwischen Bein 1 und 2
// LED grün an Pin 7, LED rot an Pin 8 (je mit 220 Ohm an GND)
#include <DHT.h>

DHT dht(2, DHT11);
float maxTemperatur = 25.0;
float maxFeuchte = 60.0;

void setup() {
  pinMode(7, OUTPUT);
  pinMode(8, OUTPUT);
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  // nur alle 2 s messen
  delay(2000);
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (isnan(t) || isnan(h)) {
    Serial.println("Sensorfehler: Kabel pruefen");
    return;
  }
  Serial.print("Temperatur: ");
  Serial.print(t);
  Serial.print(" C, Luftfeuchte: ");
  Serial.print(h);
  Serial.println(" %");
  if (t > maxTemperatur && h > maxFeuchte) {
    // warm und feucht: lüften, rot
    digitalWrite(7, LOW);
    digitalWrite(8, HIGH);
  } else {
    // alles in Ordnung: grün
    digitalWrite(7, HIGH);
    digitalWrite(8, LOW);
  }
}
